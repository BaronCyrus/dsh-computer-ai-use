# v0.2.0：走官方插件页安装，设置里可以自动更新

现在可以在 DSH 的“插件”页正常安装本插件，并在设置里管理版本和自动更新。

- **官方安装流程**：“插件 > 添加插件”填包名即可，不用改配置，也不用重启。插件页有图标和中英文介绍。
- **设置页**：“设置 > Computer AI Use”显示当前版本，可以检查更新，也可以点“立即更新”马上安装。
- **自动更新（默认开启）**：打开 DSH 约一分钟后检查一次，之后每 6 小时检查一次，在后台安装新版本，重新打开 DSH 后生效。
- **自动更新只安装可信的版本**：必须发布满 24 小时、经本仓库的发布流程发布（有 npm 来源证明）、没有被废弃，并且兼容当前的 DSH。不满足时设置页会说明原因，你仍然可以手动更新（不兼容的版本除外）。
- **不和插件页抢占**：更新和“插件”页共用同一把 profile 锁，失败时恢复 profile 文件，也不绕过 pnpm 的发布冷却策略。
- **以后的版本带来源证明**：从这个版本起由 GitHub Actions 发布到 npm。0.1.0 是本地发布的占位版本，不含以上功能。

验证：测试覆盖单元逻辑、设置页，以及用桌面版同款 pnpm 11.28.5 加本地测试源的真实更新。在 macOS 上用桌面版自己的宿主入口和临时数据目录实测了插件页安装和启用、设置页、立即更新、启动后的无人值守更新、开关跨重启生效、卸载重装。尚未在桌面版窗口里实测，也没有在 Windows 上做界面实测。

在 DSH 的设置中更新至 **0.2.0**，然后重新打开 DSH 加载新版。0.1.0 没有更新功能，请在插件页安装 `dsh-computer-ai-use@0.2.0`。
